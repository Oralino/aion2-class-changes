# AION2 Class Changes: 11/11 Update

Unofficial fan translation of the **클래스 변경사항 (Class Changes)** section of the [official 11/11 update notes](https://aion2.plaync.com/ko-kr/board/update/view?articleId=6af370b8577e8c01355e047b) (Korean server). Class and skill names use the official English names from the global client, with the Korean in parentheses. Names marked † are new in this patch and have no official English name yet, so they are my translations. "Spec N" means the Nth specialization (특화). Not affiliated with NCSOFT.
